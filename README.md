# 基于视觉伺服的机械臂动态追踪与抛接系统

## 1. 项目背景与目标

本项目旨在利用**ROS通信**、 **CoppeliaSim 仿真平台** 和 **ViSP 视觉库**，开发并验证一套 **视觉引导的机械臂控制方案**，实现两类典型任务：

- **动态目标追踪**：机械臂末端实时跟踪一个带有视觉标记（四个圆点或 AprilTag）的运动平板，保持固定的相对位姿。
- **动态目标抛接**：在追踪基础上，加入运动预测、拦截点计算与夹爪控制，模拟接住一个抛掷物体的过程。

## 4. 追踪任务（基于视觉）

### 目标

使机械臂末端始终跟随平板的位姿，平板在仿真场景中沿矩形路径平移并绕自身轴摆动（由 `/Plane/Script` 驱动）。

### 实现流程

1. 视觉传感器采集图像并发布到 `/image`。
2. 视觉节点检测标记点，利用已知 3D 模型求解 **相机→目标（cMo）**，再结合预标定的 **世界→相机（wMc）**，计算 **世界→目标（wMo）**。
3. 将 `wMo` 转换为四元数+平移，发布到 `/f_M_o`。
4. CoppeliaSim 中 `UR5/Target` 脚本订阅 `/f_M_o`，更新 IK 目标点。
5. UR5 IK 控制器（`/UR5/Script`）驱动关节，使末端到达目标位姿。

## 5. 抛接任务

### 目标

在追踪基础上，增加 **目标运动预测** 与 **自动抓取**，模拟接住飞来的球体。

### 实现流程（区别于追踪）

1. 直接通过 `sim.getObjectPosition()` 获取目标物体的真实坐标（这里作弊了，应该用视觉信息）
2. 用前后帧位置差分计算速度，并预测未来位置（含重力补偿）。
3. 根据距离调整接近阶段，计算拦截点，使末端提前运动到预测点。
4. 当末端与目标距离小于阈值时，自动闭合夹爪（力控模式）。

## 6. 技术栈与依赖

| 组件 | 说明 |
|------|------|
| **仿真平台** | CoppeliaSim（V‑REP）4.0+，Lua 脚本 |
| **视觉库** | ViSP 3.5+（AprilTag、blob 检测、位姿求解、显示） |
| **通信** | ROS 1（Melodic/Noetic），使用 `cv_bridge`、`sensor_msgs`、`std_msgs` |
| **运动学** | UR5 标准 DH 参数，IK 采用伪逆或阻尼最小二乘法 |
| **编译** | CMake，链接 ViSP、OpenCV、Boost、ROS 库 |

## 7. 作者的话

- Coppeliasm是个极其小众的仿真平台，没办法，老师指定的，所以上传场景的ttt文件之外还把其中的脚本全提取出来用txt上传了。
- 这是眼在手外的系统，也就是说有个深度相机固定在某个同时能看到机械臂与目标物的地方。说真的，还是眼在手上的系统更成熟，应用更广泛，导致我们找不到很多参考资料。
- 由于一些意外，实验设备没了，导致仿真结果无法实机部署。追踪的仿真结果还好，部署成功的可能性大。抛接的难度很高，时间也不够，只好在验收时走捷径了，若部署还要大量调整和测试。
- 本来计划是三种检测目标：blob、apriltag以及无标识物体（球、正方体、圆柱体等），前两者能实现精确的位姿计算，而后者不能，没有通过实验验证后者算法的有效性。
- 除了单臂抛接，对双臂抛接也进行了尝试，虽然成功了几次，却是在单臂的基础上调整距离和角度的偏置量实现的，就不上传了。
